# Protocole de Session de l'Agent

## Règle de démarrage systématique
À chaque nouvelle session, l'agent doit impérativement consulter [`SESSION_STATE.md`](file:///d:/Bureau/Site%20Agroalimentaire/SESSION_STATE.md) à la racine du projet pour :
1. Être immédiatement synchronisé avec la progression réelle du projet (audit de code, modèles, vues, corrections récentes).
2. Vérifier les tâches prioritaires définies dans la feuille de route (P1 Internationalisation, P2 Backend API, P3 Export PDF Officiel, P4 SEO/Performance, P5 Déploiement).
3. Assurer la continuité sans répéter des étapes déjà validées.
